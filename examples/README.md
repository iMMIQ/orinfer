# Client & Diagnostic Examples

Ready-to-use configuration templates and sample inputs for connecting external tools or running diagnostics against Orinfer.

| File | Purpose | Documentation |
| --- | --- | --- |
| `opencode.json` | [OpenCode](https://github.com/anomalyco/opencode) provider config (`orinfer/qwen-flash-next`, `orinfer/deepseek-v4.1`) with thinking variants & vision | [Serving Guide](../docs/serving.md#8-coding-agent-integrations) |
| `pi-models.json` | [Pi](https://github.com/earendil-works/pi) `models.json` provider snippet (`openai-completions`) | [Serving Guide](../docs/serving.md#8-coding-agent-integrations) |
| `dsh-cordis.patch.yml` | [DeepSeek Harness (`dsh`)](https://github.com/deepseek-ai/deepseek-harness) headless profile patch | [DeepSeek Harness Guide](../docs/deepseek-harness.md) |
| `requests.json` | Sample token-ID request payload for `orinfer run-model` | [Serving Guide](../docs/serving.md#9-diagnostic-cli-commands) |
